# График ассистентов

Веб-программа для составления графика ассистентов стоматолога: клиники и кресла, базовая неделя врачей, даты работы ассистентов, автозаполнение, выгрузка в PDF, картинку и Word.

- Сайт: https://mregorik.github.io/grafik/
- Данные хранятся в Supabase (вход по паролю), в этом репозитории только код страницы.
