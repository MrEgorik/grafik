# График ассистентов

Веб-программа для составления графика ассистентов стоматолога: клиники и кресла, базовая неделя врачей, даты работы ассистентов, автозаполнение, выгрузка в PDF, картинку и Word.

- Сайт: https://mregorik.github.io/grafik/
- Данные хранятся в Supabase (вход по паролю), в этом репозитории только код страницы.

## Рабочая и тестовая версии
- Рабочая: https://mregorik.github.io/grafik/ — ей пользуются клиники. Обновляется только по команде владельца.
- Тестовая: https://mregorik.github.io/grafik/test/ — отдельная база данных, все доработки сначала выкладываются сюда.
- `supabase/schema.sql` — полная схема базы, `supabase/history.sql` — история изменений (защита от потери данных).
